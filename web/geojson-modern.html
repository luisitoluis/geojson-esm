Sin dependencias

Un único archivo fuente, cero paquetes de terceros en producción. Menos superficie, menos sorpresas.

ESM + CJS

Build dual con tsup: import nativo o require(), tú eliges.

Tipada

Definiciones .d.ts incluidas para autocompletado en TypeScript sin migrar el código fuente.

Probada

Suite de tests con Vitest cubriendo cada tipo de geometría y cada opción del parser.

Instalación

Tres líneas y estás convirtiendo datos.

import { parse } from "geojson-modern";

const geojson = parse(data, { Point: ["lat", "lng"] });

Referencia rápida

Opciones del método parse
Opción Tipo Descripción
Point [string, string] Atributos [lat, lng] del objeto de origen.
LineString / Polygon / Multi* string Atributo que contiene los datos de coordenadas anidados.
include string[] Lista blanca de atributos a incluir en properties.
exclude string[] Lista negra de atributos a excluir de properties.
bbox boolean Calcula el bounding box de la colección y de cada feature.
removeInvalidGeometries boolean Omite en vez de lanzar error los elementos sin geometría válida.
